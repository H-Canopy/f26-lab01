## 三条铁律

1. **每张终端证据，先跑 `git branch --show-current` 再跑主命令。**
   否则助教无法判断这个结论是在哪条分支上得到的。
2. **能贴文本/链接的，绝不用截图。**
   - 终端输出 → 存 `.txt`（可搜索、可复制复现、不会糊）
   - GitHub 的 commit / PR / diff → **直接贴链接**（永久、可点开、改不了）
   - **只有 IDE 界面**（断点调试等）才必须截图
3. **统一存放 `docs/evidence/`，命名 `M<成员>-<里程碑>-<序号>-<说明>.txt|png`。**
   每个文件顶部加一段头注释（谁 / 哪条分支 / 时间 / 对应评分点 / 采集命令）。

```
# 证据 M4-m2-03：晋升测试在"只删除"实现上失败
# 采集人 : Twh743 (M4)
# 分支   : test/cancel-booking
# 时间   : 2026-10-10 14:20:00
# 用途   : 实验报告 第 4.5 节 / 评分点「里程碑2 · 晋升测试有说服力 10 分」
# 命令   : mvn test -Dtest=CancelBookingTest
```

> ⚠️ 截图前关掉无关窗口：**特别是别把 `transcripts/` 的内容或 `~/.claude/` 下的配置文件带进画面**
> （里面有明文 API 凭据）。
